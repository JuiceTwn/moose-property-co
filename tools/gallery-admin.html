Step 1 — Connect to GitHub

One-time setup Not connected

This site has no server, so photos are published by saving them into the website's code on GitHub. To let this page do that, it needs an access key from your GitHub account.

Do not fancy setting this up? You do not have to. Drag photos straight into the photos folder on GitHub instead — your normal GitHub login works there and no key is involved. They get shrunk and added to the gallery automatically. Name a file like fencing-chesley.jpg and it files itself under Fencing. This page is just the tidier way to do the same job, with captions typed in a box.
Keep this key private. It stays in this browser only — it is never uploaded, never committed, and no one visiting the website can see it. Anyone who has both your unlocked device and this key could change the website, so use a key limited to just this one repository:
  1. Open GitHub → Fine-grained tokens → Generate new
  2. Under Repository access, pick Only select repositories → moose-property-co
  3. Under Permissions → Repository permissions, set Contents to Read and write. Leave everything else alone.
  4. Set an expiry you are happy with, generate it, and paste it below.
If a key ever leaks, delete it on that same GitHub page and it stops working immediately.
